CH 内容中台 · 功能简介

8-Agent 内容自动化生产 + 社媒分发流水线

一句话定位

从全网拉素材，自动分类起标题、生成封面、合规审核、发布到站、改写后分发到社媒，并回流数据形成闭环。

流水线总览

选源 → 采集 → 分类+标题 → 封面 → 合规 → 发布* → 分发* → 数据回流

* 标记为人工闸口，自动模式下不会触发，需要手动放行。

核心能力

多源采集

RSS、HTML、Reddit、Bluesky、X、Sitemap 等 8 类适配器，支持反盗链头部。

三层去重

URL dedupe_key + 内容 hash + simhash 模糊匹配（汉明距离 ≤3 视为重复）。

分类 + 标题

LLM 给类目/tags/keywords，再生成 N 条标题候选挑最优，自动出唯一 slug。

智能封面

从素材里按分辨率打分挑封面，多尺寸压制传 S3，HTML 源额外做图集。

两层合规

L1 正则黑名单（cheap），L2 LLM 6 维度打分；命中黑名单永远 FAIL。

站内发布

写 published_url，触发 Next.js ISR 刷四个路径（首页/文章/分类/sitemap）。

社媒分发

按平台调性改写文案（X 280 字符预算 + hashtag），写入 distribution_tasks 等执行。

数据回流

GA4 拉昨日 PV/UV/时长，每周生成 Top 10 + 趋势 markdown 报表。

8 个 Agent 一览

#Agent职责关键产出
1source-scoring给信源打分（纯 SQL）sources.score / risk_level / status
2ingestion采集 + 清洗 + 去重raw_items + items (INGESTED)
3classify-title分类 + 起标题 + slugcategory / tags / title / slug
4cover封面挑选 + 压制 + 文案cover_url / cover_sizes / cover_copy
5compliance风险审核（黑名单 + LLM）COMPLIANCE_PASS / REVIEW / FAIL
6publishing正式发布 + ISR 刷新published_url + 站内可访问
7distribution社媒文案改写 + 入队distribution_tasks (pending)
8analyticsGA4 回流 + 周报analytics_daily + 报表 markdown

状态机

INGESTED → CLASSIFIED → TITLED → COVERED → COMPLIANCE_PASS → PUBLISHED → DISTRIBUTED

每步都有状态守门，串错状态自动跳过。COMPLIANCE_REVIEW / COMPLIANCE_FAIL 会停在原地等人工。

设计亮点

  • Agent 解耦：每个 agent 独立队列、独立重试、独立部署。
  • 降级路径：每个 LLM agent 都有 *_SKIP_LLM=1 规则版兜底，没配额也能跑。
  • 幂等去重：jobId 用 <agent>__<itemId>，并发触发只跑一次。
  • 人工闸口：发布 / 分发硬卡点，auto-pipeline 永不触发。
  • 全程可观测：每次调用进 agent_runs，记录 model / token / cost / latency / 错误。

技术栈

后端Node 20 · Fastify · BullMQ · MySQL 8 · Redis 6
前端Next.js（站内 + admin 控制台）

LLMGroq（OpenAI 兼容协议）
监控Sentry + 自定义 alerts poller
