内容中台 · 操作指南

非技术人员日常使用步骤

你只需要在浏览器里打开公司的内容中台后台地址，登录后就能完成所有操作。 本指南描述每个页面是干什么的、什么时候需要你点一下。

第一次使用前：找运维或技术同事拿到后台地址、账号密码。系统部署、信源初始化这些一次性的事，由技术同事负责。

二、第一次怎么用（5 分钟）

登录后台

用技术同事给你的地址（类似 后台.公司域名.com/admin）打开，输入账号密码。

到 "内容源" 页面，添加你要监控的来源

点 "新增信源" 按钮，填几个字段：

  • 类型：选 RSS / HTML / Reddit 等（不确定的话选 RSS 多半都行）
  • 名称：随便起，自己看得懂就行（如 "TechCrunch"）
  • 地址：粘贴 RSS 地址或网页地址

保存。系统会在下一轮采集（通常每小时一次）开始拉这个源。

等系统跑一会儿

大约 10–30 分钟后回到 "总览" 页面，应该能看到陆续有文章进入流水线。

处理 "待审核" 的文章

到 "待审核" 页面，看每篇文章被标记为待复核的原因，决定放行还是拒绝。

选择要发布的文章

到 "待发布" 页面，预览每篇的标题 / 封面 / 摘要，勾选后点 "确认发布"，文章马上在你的网站上可见。

选择发到哪些社媒

到 "待分发" 页面，看系统已经写好的推文文案。觉得合适就勾选 + 确认，不满意可以编辑后再发。

三、日常工作流程

建议每天花 15–30 分钟跑一遍下面的循环：

早上：看总览

打开 "总览"，看昨天产出多少、当前每个阶段堆了多少。如果 "待审核" 或 "待发布" 堆得很多，今天要重点处理。

处理 "待审核"

逐篇判断系统给的合规理由对不对：

  • 觉得没问题 → 点放行
  • 确实有风险 → 点拒绝（这篇就到此为止，不会再走下去）
  • 拿不准 → 跳过（保留在队列里晚点再看）
选稿发布

到 "待发布" 页面，预览每篇的标题封面分类摘要，勾选你想发的。 如果想给标题做最后调整，可以点编辑。

分发到社媒

到 "待分发" 页面，系统已经为每个平台准备好了文案。检查文案 → 选平台 → 确认发出。

下班前：看一眼数据

到 "数据" 页面看今天发的文章是否有进站访问。周五看一下本周 Top 10 报表。

四、常见场景

我加了一个新的内容源，但是没看到内容

采集是按小时来的，加完之后等 1 小时左右。如果想立刻试，可以点 "立即采集" 按钮（在 "内容源" 页面每行的操作栏里）。

这篇文章的标题我不喜欢

在 "分类 + 标题" 或 "待发布" 页面点 "重新生成标题"，系统会再起一组候选。也可以直接编辑改成你想要的。

封面图不太合适

系统是从原文里挑的图。你可以在文章详情页的 "图集" 区切换其他候选图，或者上传一张自己的。

这篇文章被合规拦下来了，但我觉得没问题

到 "待审核" 看具体原因。如果你判断系统过于敏感，点放行就会继续往后走。但要为这个判断负责。

有篇文章我想紧急下架

找到那篇文章 → 点 "回滚到上一状态" → 文章会从网站下线（具体下线在网站上多久内生效，由部署的缓存策略决定）。

某个内容源最近老出问题，先暂停

"内容源" 页面找到它，点 "暂停"。系统就不再从它那里拉新内容了。想恢复时再点 "激活"。

系统推文文案我想改一下

"待分发" 页面每条推文都可以编辑。改完保存再点发出即可。

五、状态标签的意思

每篇文章在不同阶段会带不同的状态标签：

  • 已采集 系统刚拉回来，还没处理
  • 已分类 已经分好品类、有 tags
  • 已起标题 已经生成新标题、摘要、网址
  • 已配封面 已经选好封面图
  • 合规通过 自动审核通过，等你决定发不发
  • 待复核 自动审核拿不准，需要人工判断
  • 合规未通过 自动审核拒绝，不会自动发布
  • 已发布 文章已在网站上线
  • 已分发 已发到至少一个社媒

六、紧急情况

系统出了问题，全部停下来

"总览" 页面有个红色的 "急停" 按钮，点一下整个流水线就停止采集和处理。已发布的文章不受影响。等问题解决后点 "恢复"。

停掉某个阶段

不想全停的话，可以只暂停某一步（比如只暂停采集）。在 "总览" 或 "管线控制" 页面找到对应开关。

七、什么时候需要找技术同事

想接入新的平台（比如小红书、抖音、Telegram）
需要技术同事写一个新适配器，几天到一周的工作量。
系统报错 / 后台某个页面打不开
截图发给技术同事，附带操作时间。
想批量改一批文章的分类或标题
页面上能改单篇，批量需要技术同事跑一次脚本。
想加 / 改合规规则（比如"屏蔽关键词 X"）
关键词列表在代码里，需要技术同事修改后重新部署。
系统好像漏抓了某条内容
有可能被去重了，也可能信源那边格式变了。把 URL 发给技术同事查一下。
想要某个数据指标（"按作者维度看 PV"之类）
当前周报是固定模板，自定义维度的数据需要技术同事查库。

八、几条小建议

  • 不要点了发布就不管 — 发布后过 10 分钟到网站上看一下文章页是不是好的。
  • 合规拿不准就拒绝 — 出问题的代价远大于错过一篇文章。
  • 定期清理低质源 — 每周看看哪些信源产出少 / 合规失败多，暂停掉。
  • 分发别一次发太多 — 短时间往同一个社媒账号发太多容易触发对方风控。
  • 周报每周看一次 — 能帮你发现哪个品类、哪个时间段的内容更受欢迎。
